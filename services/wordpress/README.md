# WordPress Headless Layer

This directory contains custom WordPress extensions used by Project Apex.

## Included

- `plugins/apex-core`: starter plugin for core CPT registration and REST route stubs.

## Planned Expansion

- ACF field groups for `lead`, `vehicle`, and `work_order` objects.
- JWT-based dashboard authentication flow.
- Headless API enhancements (REST and/or WPGraphQL conventions).
